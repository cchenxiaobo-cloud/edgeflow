## 3. 异常路径处理建议（部署/升级场景）

### 3.1 升级中途失败
- keadm upgrade 失败 → 台账 failed + 提示 `keadm rollback --latest`（已有，实测）
- 补充建议：失败后先 `ops-ledger` 确认失败原因再决定重试或回滚

### 3.2 回滚本身失败
- 已有兜底：备份保留 + 人工 cp 提示 + 重跑幂等（M4D P2-4 事务化后）
- 补充建议：回滚前对 output-dir 再做一次快照（回滚失败可回到回滚前状态）

### 3.3 数据迁移异常
- 当前无数据迁移逻辑（升级只动产物文件，数据目录不动）
- 若未来加入迁移：先备份数据目录 → 迁移 → 校验 → 更新版本标记；失败回滚数据

### 3.4 镜像发布失败
- CI release.yml 已含 imagetools inspect 自检（缺失即失败）
- 回滚预案：MULTIARCH.md §6（指回旧 digest / 单架构覆盖 tag）
