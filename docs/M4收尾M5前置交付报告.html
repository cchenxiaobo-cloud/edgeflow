2. 升级回滚机制（10.2）

keadm upgrade --version=v0.2.0 ① 版本格式校验 → ② 备份产物（backups/<ts>/manifest+sha256） → ③ 更新 env 版本标记 → ③b 刷新 reset 校验清单 → ④ 台账 任一环节失败：台账 failed + 提示 rollback --latest；--simulate-failure 演练 keadm rollback [--backup=<id>|--latest] 完整性校验（manifest+sha256）→ 恢复 3 产物（复制+回读+权限）→ 刷新清单 → 台账 失败兜底：备份保留 + 人工 cp 提示 + 重跑幂等 台账 ops-ledger.jsonl：{ts, action, from, to, result, operator, note} 追加写
