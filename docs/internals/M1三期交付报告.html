3. 可靠投递链路（WBS 4.6）

云端控制器 / 管理 API │ POST /api/v1/nodes/{id}/podsync ▼ CloudHub.ReliableSend ── pending[msgID] → 等待 Ack（默认 5s） │ 超时 → 重发同 ID（默认 2 次）→ 耗尽返回 ErrAckTimeout ▼ WebSocket EdgeHub.handleDownlink │ ① 幂等查询（processed 缓存，上限 1000 FIFO） │ ② 执行 handler（PodSync → MetaManager.SavePod 落盘 SQLite） │ ③ 成功 → 记缓存 + 回 Ack(code=ok) ｜ 失败 → 回 Ack(code=error) 不入缓存 ▼ 云端收到 Ack → 匹配 pending → ReliableSend 返回 nil（确认完成） 幂等语义（QoS 1：至少一次 + 去重）： 重发同 ID → 缓存命中 → 不重复执行，直接回 ok handler 失败重试 → 缓存未记录 → 允许重新执行
