1. 本轮交付摘要

本轮完成两个方向：MQTT EventBus（WBS 3.6）——边缘设备数据面的 MQTT 总线（mosquitto + paho 封装，QoS1 + 自动重连 + 订阅恢复）；ConfigMap/Secret 下发（WBS 6.2，M2 完整化）——复用 PodSync 可靠投递模式。审查发现 2 项 P1（Secret 明文进日志、EventBus 重连窗口 map 竞态可致 fatal panic）已根因修复并补竞态回归测试。
