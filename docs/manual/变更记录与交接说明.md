## 三、交接说明

### 手册中暂未覆盖的功能（未实现/范围外，附录 E 有清单）
- NodeJob（已关闭，协议占位）、完整 RBAC 角色模型（仅单 Token）、设备认证 token 消费（预留）、Flannel 网络、调度/超卖、OPC-UA、API 兼容矩阵、镜像安全扫描、压缩/Protobuf、灰度发布——均未实现，手册未写入操作说明。

### 已知风险
- 云端状态为内存态：重启后需边缘节点重连自动重新注册（文档已说明）。
- 真实多节点集群与 100 节点压测未在真实集群验证（kind 单节点已跑通）；镜像未推送远端仓库；GitHub remote 未配置。
- E2E 演示依赖 Docker daemon；macOS 本机 NodePort 受限（文档已说明）。
- 手册由人工撰写+复核，新版本发布后需同步更新（见下）。

### 后续更新建议
1. 每次发版后按 README.md"更新方式"修订对应章节与附录 D 变更记录；
2. 新增功能上线后，把"即将上线"条目移入正文操作说明；
3. 真实集群验证完成后，补充多节点部署与压测章节（当前为已知限制）；
4. 如新增 API/环境变量，同步更新第 4 章与附录 A（附录 A 是复核重点项）。
