## 3. 口径假设声明（交付时需向用户/客户说明）

1. **模型管理/模型应用场景**以产品真实能力为基线：Edged 容器化部署推理服务、config-sync 配置下发、镜像分发、多副本健康自愈；模型仓库/版本管理/灰度发布标注"规划中/即将上线"（ROADMAP 依据），方案给出"镜像 Tag + 配置参数化"过渡路径。
2. **评审留痕**：产品/方案团队人工评审由**独立技术复核 Agent** 替代执行（本文件第 2 节即复核留痕）；正式对外发布前建议产品团队按第 2 节清单做一次人工确认。
3. **未验证项如实标注**：GPU/异构加速未验证、断网自治 30min 长跑 E2E 未验证（POC 层已验证）、EventBus 降级本地模式恢复需重启 edgecore。
4. 手册中命令与字段为示意用法（已逐处注明"以产品文档为准"）。

## 4. 版本管理与回滚口径

- 主源文件为 `EdgeFlow-解决方案手册-v1.0.0.md`，HTML/PDF/CSV 为同版本衍生制品；修订须更新主源文件的"修订记录"表并重新生成全部衍生制品。
- 产品新版本发布后，对照附录 C 特性清单逐条核验"已实现/规划中"状态后再升版。
- 若某版本发现事实性错误：回退到上一 Git 提交并发布勘误版本（vX.Y.Z+1），不直接修改已发布历史版本；勘误记录写入修订记录表。
- 本次 Git 提交：见提交记录（含主文档、衍生品、图表源文件与 PNG、映射表、本文件）。
